# Backend Test Writer Memory

누락됐던 테스트 유형과 회귀 케이스를 누적한다.

## Usage

- 구현 후 발견된 누락 테스트, self-heal로 드러난 테스트 공백을 기록한다.
- 다음 RED 단계에서 EXEC_PLAN의 테스트 케이스와 대조한다.
- 프로젝트 전체 규칙으로 승격할 내용은 `docs/spec/test-strategy.md` 또는 agent 지침에 반영한다.
