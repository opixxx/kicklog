✕오탐 / 분석 중 해소된 의심

해소DTO camelCase 디코딩 실패 우려

분석 에이전트가 "백엔드가 snake_case 면 디코딩 실패" 우려를 제기했으나, Spring Boot Jackson 기본 직렬화는 camelCase 이고 api-spec 예시(displayName, createdAt)도 camelCase — 문제없음.

해소토큰 갱신 동시성 / 토큰 저장 보안

TokenRefresher 는 actor + in-flight Task 공유로 동시 401 을 단일 refresh 로 dedup — 올바른 구현. 토큰은 Keychain 에 kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly 로 저장 (iCloud 동기화 차단) — 모범 사례. DebugWorkoutSeeder 도 파일 전체 #if DEBUG 로 Release 제외 확인.
